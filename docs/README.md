# docs/

- `guidelines/` — house rules and lessons learned that apply to future dataset work (stable, short, reference these).
- `plans/` — work to do, one file per effort, updated as work lands (delete or archive when done).

Dataset-specific pipelines document themselves next to the code (e.g. `datasets/prep/spatialvid_hq/README.md`).
Dataset cards (methods-ready descriptions) live in `datasets/cards/` (planned; see `plans/spatialvid-hq-next-steps.md`).
